# Iteration 23J — Bounded Research Semantics

## BOUNDED_RESEARCH_ALLOWED
**YES** means:
- certified available horizons may run now
- no long-history truth is implied
- full qualification is not implied
- LIVE remains forbidden

### Explicit non-implications
`BOUNDED_RESEARCH_ALLOWED = YES` does **not** mean:
- `LONG_HISTORY_READY = YES`
- `23F_FULL_CAMPAIGN_ALLOWED = YES`
- `FULLY_QUALIFIED = YES`
- `EXECUTION_ELIGIBLE = YES`

## Qualification matrix
- `RESEARCH_ONLY`
- `BOUNDED_VALIDATED`
- `LONG_HISTORY_PENDING`
- `FULLY_QUALIFIED`
- `EXECUTION_ELIGIBLE`

## Rejection rule
There is no path from bounded validation to full qualification that bypasses a genuine certified 1095d pass.

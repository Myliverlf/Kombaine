# Failure Modes Observed

## 1. Identity weakness
File paths and synthetic aliases can stand in for instrument identity unless explicitly checked.

## 2. Data lineage fragmentation
Truth is distributed across CSV filenames, registry labels, policy JSON, and reports.

## 3. Horizon semantics drift
Nominal labels can mislead unless actual coverage and source file are verified.

## 4. Behavioral duplication inflation
Multiple parameter variants can overstate independent evidence.

## 5. Promotion semantics coupling
Research validation, forward eligibility, and live readiness are not fully separated everywhere.

## 6. Legacy semantic debt
Legacy campaign scripts and multiple contract layers coexist, increasing the chance of inconsistent truth.

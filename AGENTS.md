# AGENTS.md — правила для любого агента/нейросети в этом проекте

ПЕРВЫМ делом прочитай **START.md** (карта системы + жёсткие правила), затем
**ARCHITECTURE.md** раздел 9 (реальный рабочий контур).

Коротко о запретах:
- LIVE/брокерские вызовы — ЗАПРЕЩЕНЫ (mode=paper, debug_only=True всегда)
- Живые слоты SBER SHORT и LKOH 15m LONG — не трогать
- git reset/clean/commit — не делать
- Гейты отбора (tools/select_stable_pool.py) — не ослаблять НИКОГДА;
  улучшать можно только движки в engines/ и ДНК в engines/genome.py
- RAM мало — тяжёлые прогоны последовательно, не параллельно
- Графики — ТОЛЬКО в стиле lieflat-charts через tools/lieflat_render.py (раздел
  ГРАФИКИ в START.md); голый matplotlib запрещён
- После КАЖДОГО прогона движка/обучения — ОБЯЗАТЕЛЬНО честный бэктест и
  сравнение с предыдущим лучшим («что было → что стало»); результат писать в
  историю (state/nn_leaderboard.json, engine_candidates.json). Подробности — START.md
  раздел «ПРАВИЛО: БЭКТЕСТ И СРАВНЕНИЕ ПОСЛЕ КАЖДОГО ПРОГОНА».

Точные команды запуска — в START.md.
